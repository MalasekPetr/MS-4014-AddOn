# Opakování a další kroky

## Shrnutí dne v pěti větách

1. Microsoft vyhrává distribuci AI ve firmách, modelová vrstva je multi-model — Copilot dnes používá modely OpenAI, Anthropic i Microsoft.
2. Copilot stojí na čtyřech pilířích: **Chat, Cowork, Code, Autopilot**; část je GA, část ve Frontier.
3. Copilot rozšiřujete **skills** (jak), **connectors** (k čemu) a **kontextem** (Projects, Workspaces).
4. Agenti se staví třemi přístupy — **Agent Builder, Copilot Studio, Foundry** — a napojují přes **Microsoft IQ, MCP a A2A**.
5. Každý agent má **identitu, sponzora a rozpočet**; řídí se v **Agent 365** a plánuje se **před** stavbou.

## Opakovací otázky

1. Jaký je rozdíl mezi Copilot Chat a Copilot Cowork?
2. Co obsahuje Cowork plugin?
3. Kdy data z konektoru opouštějí tenant?
4. Čím se liší Project a Workspace?
5. Který přístup ke stavbě agenta zvolíte pro produkční systém s vlastní orchestrací?
6. Která služba IQ odpovídá za e-maily, Teams a soubory?
7. Co je agent identity blueprint?
8. Které funkce čerpají Copilot Credits a jak útraty omezit?
9. Kde se dědí governance automaticky a kde ne?
10. Proč měřit baseline před spuštěním agenta?
